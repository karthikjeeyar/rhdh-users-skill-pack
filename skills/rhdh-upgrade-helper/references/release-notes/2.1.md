# RHDH 2.1 Release Notes

Red Hat Developer Hub 2.1 is based on upstream Backstage 1.54.9, Node.js 24.21.0, and CLI 2.1.2.

Sources: [RHDH 2.1 release notes](https://docs.redhat.com/en/documentation/red_hat_developer_hub/2.1/whats_new-red_hat_developer_hub_release_notes) and [RHDH 2.1 migration guide](https://docs.redhat.com/en/documentation/red_hat_developer_hub/2.1/migrate-migrate_from_rhdh_1_x_to_2_1).

This curated file focuses on upgrade-relevant facts verified for the `rhdh-upgrade-helper`. Consult the linked release notes for the complete feature, known-issue, and advisory lists.

## New features and enhancements

- **RHDH 2.1 is generally available** and uses Backstage 1.54.9, Node.js 24.21.0, and CLI 2.1.2.
- **Developer Lightspeed is now Intelligent Assistant**. The 2.1 implementation uses LCORE instead of Llama Stack; app-config keys and the route use the new `intelligent-assistant` name.
- **Helm supports an in-place chart upgrade** from 1.y to 2.1; uninstalling the existing release is not required.

## Deprecated features

- **Dynamic-plugin `disabled` configuration is deprecated** in favor of `enabled`. The deprecation has been announced; removal is planned for RHDH 2.3. Treat migration to `enabled` as informational for 2.1, and do not rewrite it automatically.
- **Orchestrator per-workflow permission strings** are deprecated; use conditional policies for workflow-specific access.

## Removed features

- Bundled plugin wrappers under `./dynamic-plugins/dist/` are removed; use the target release's declared plugin artifact, such as `ref://` or an exact `oci://` reference.
- The old frontend system is removed. Frontend plugin wiring moves from `dynamicPlugins.frontend` to `app.extensions` and `app.routes.bindings`; remove `APP_CONFIG_app_packageName=app-next` and `ENABLE_STANDARD_MODULE_FEDERATION=true`.
- Authentication providers are not installed by default; install the required backend provider as a dynamic plugin and retain its settings under `auth.providers.<id>`. Replace auxiliary-provider `disableIdentityResolution` with `signIn.resolvers: []`; install/configure Guest explicitly instead of relying on development mode.
- The Global Floating Action Button and `dynamic-home-page` packages are removed; `homepage` is added for the new frontend system. The 2.1 dynamic-plugin comparison lists `@backstage-community/plugin-catalog-backend-module-pingidentity` as unavailable.
- The Plugin Certification Program is removed.
- The RAG content image `rhdh-rag-content-rhel9:1.10` is removed. Product images using `*-rhel9` names are renamed to `*-rhel10`; the Intelligent Assistant sidecar (`lightspeed-stack-rhel9`) and Offline Knowledge Portal image (`rhokp-rhel9`) remain RHEL 9 images.
